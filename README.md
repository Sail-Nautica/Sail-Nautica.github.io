## 👋 About Me

I'm an engineering student at **The University of Michigan** who builds small tools for problems I run into. Whether it's promotion paperwork, logging rowing workouts, or calendars that refuse to talk to each other.

Most of my time goes to C++ coursework, Swift app development, and a JavaScript tracker now used to plan **Civil Air Patrol** cadet promotions. I also work on the programming & navigation sub team on **Michigan Autonomous Aerial Vehicles (MAAV)**.

- 🔨 Currently building → [**RowPilot**](https://github.com/Sail-Nautica/RowPilot), on-water workout collection for rowing
- 📦 Shipped → [**CAP Cadet Promotion Tracker**](https://sail-nautica.github.io/CAP-Cadet-Promotion-Tracker/): upload a full-track report, get overdue and upcoming promotions
- 🌱 Learning → SwiftUI, sensor data pipelines, and making things fast instead of just correct
- ⚡ Fun fact → the handle is a sailing joke I am committed to
